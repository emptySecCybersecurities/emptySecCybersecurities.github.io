# emptySec Cybersecurities

emptySec Cybersecurities - a free community supported non-profit cybersecurity learning solution .

Pure HTML/CSS/JavaScript landing page.

## Files

- `index.html`
- `style.css`
- `script.js`
- `assets/ambient.mp4` — add your optimized hero loop
- `assets/ambient.webm` — optional smaller WebM version
- `assets/ambient-poster.jpg` — first-frame poster

## Video target

Keep the ambient loop short and lightweight. A practical target is ~2–4 MB desktop and ~2 MB or less for mobile, with muted autoplay, `playsinline`, and a poster fallback.

The page works without the video: the CSS scene, grid, orbs and 3D interactions remain.

## Design

- Cinematic dark hero
- CSS 3D orbital object
- Cursor light
- Magnetic controls
- Pointer-reactive 3D cards
- Scroll-linked movement instead of generic reveal animations
- Reduced-motion support
- Mobile layout
